# Proyecto Web - Historia del Arte

Sitio web educativo sobre historia del arte con interactividad avanzada.

## ✨ Características Implementadas

- 🔄 Navegación SPA entre secciones
- 📱 Diseño completamente responsive
- 📝 Formulario de contacto con validación en tiempo real
- ✅ Feedback visual inmediato al usuario
- 📊 Análisis de usabilidad integrado
- 🎨 Diseño basado en principios de cognición

## 💻 Tecnologías Utilizadas

- HTML5
- CSS3  
- JavaScript (ES6+)

## 🎯 Cumplimiento de Evaluación Nro. 2

### ✅ 1. Análisis de Usabilidad
- 2 párrafos justificando diseño basado en principios de cognición y atención
- Explicación de colores, fuentes, contraste y jerarquía visual

### ✅ 2. Feedback Interactivo  
- Formulario con validación en tiempo real usando eventos `oninput`
- Mensajes de error/éxito inmediatos
- Reconocimiento de patrones en campos

### ✅ 3. Función de Utilidad
- Función modular `validateField()` reutilizable
- Separación de lógica de validación del código principal
